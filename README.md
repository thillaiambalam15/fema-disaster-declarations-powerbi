
# FEMA Disaster Declarations Dashboard

A Power BI dashboard built using FEMA's Disaster Declarations Summaries dataset. This dashboard looks at historical disaster declarations across the United States, with filters for time period and incident type.

## Dataset

The FEMA Disaster Declarations dataset contains records of disasters that have received an official FEMA declaration in the USA. It includes information about when and where disasters were happened, the type of incident involved, the declaration type, and the areas affected.

You download the dataset here:
https://www.fema.gov/openfema-data-page/disaster-declarations-summaries-v2

## Dashboard

The below section lists what all charts were used.

### Visuals

- **KPI Cards**: Shows key figures such as total declarations, states affected, designated areas, and average incident duration.
- **Declarations by State**: Map showing the geographic distribution of disaster declarations across the US.
- **Disaster Declarations Over Time**: Line chart showing how the number of declarations has changed over the years.
- **Declarations by Incident Type**: Horizontal bar chart comparing declrations across different disaster types.
- **Declaration Type**: Donut chart showing the breakdown of declaration types.
- **Disaster Seasonality**: Heatmap showing how different incident types are distributed across the months of the year.
- **Top 10 States by Disaster Declarations**: Highlights the states with the highest number of declarations.
- **Disaster Declarations by Decade**: Stacked chart showing declaration volumes and incident type composition across decades.

Note - I have used a dynamic card title based on the years selected. Also use the slicers to filter the visuals as per your needs.
